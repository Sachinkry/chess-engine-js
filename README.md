# JavaScript Chess Engine

A browser-based chess engine with an interactive board and a basic AI opponent using minimax with alpha-beta pruning.

## Core Features

- Legal move generation with full rule support (castling, en passant, promotion)
- FEN parsing and position updates
- Evaluation based on material balance
- Minimax + alpha-beta pruning (depth-limited)
- Interactive UI with drag-and-drop and visual move highlighting
- Turn-based play with AI response (Black only)

## Usage

1. Clone the repo.
2. Open `index.html` in any modern browser.
